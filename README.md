# Grupo 4 Projeto 1

## Sobre o projeto

Este projeto é um web site foi desenvolvido utilizando HTML, CSS, JavaScript e Bootstrap, com o objetivo de criar um site organizado, semântico e funcional.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap

## Páginas

* Home
* Sobre
* Serviços
* Galeria
* Contato

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo index.html no navegador ou utilize o Live Server.
